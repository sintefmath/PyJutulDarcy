API reference
=============

Public functions are available directly from ``import jutuldarcy as jd``.
The reference groups them by their defining Python module and includes their
Python signatures. Julia keyword arguments are forwarded after conversion; see
the `upstream API <https://sintefmath.github.io/JutulDarcy.jl/dev/man/highlevel/>`_
for the full option lists and physical interpretation.
