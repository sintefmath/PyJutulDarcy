# Python API

All public functions below are available as `jutuldarcy.<name>`. Keyword
arguments are converted and forwarded to Julia. Consult the
[Julia API](https://sintefmath.github.io/JutulDarcy.jl/stable/man/highlevel/)
for the full keyword lists and physical interpretation.
