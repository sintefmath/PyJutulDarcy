PyJutulDarcy
============

PyJutulDarcy makes `JutulDarcy.jl <https://github.com/sintefmath/JutulDarcy.jl>`_
available from Python. These pages describe the Python interface: installing the
Julia environment, converting values, selecting execution backends and working
with results.

For reservoir physics, model options and full simulation examples, use the
`JutulDarcy documentation <https://sintefmath.github.io/JutulDarcy.jl/dev/>`_.
The repository's `README <https://github.com/sintefmath/PyJutulDarcy#readme>`_
and `examples <https://github.com/sintefmath/PyJutulDarcy/tree/main/examples>`_
provide a starting point for running simulations.
